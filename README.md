# 網膜モデル教科書

`convis` / VirtualRetina が何をどう計算しているかを、大学数学や微積分が怪しい人向けに
ゼロから説明する教科書。

- `retina_textbook.html` — 本体（単一HTMLファイル）。ブラウザで直接開ける
- 構成：準備運動（畳み込み・ガウシアン・微積分の基礎）→ 全体地図 → OPL（中心・周辺差分）
  → 双極細胞・非線形フィードバック → 神経節細胞・スパイク → まとめ、の8章構成
- 元になったコードの解説は [convis-legacy](https://github.com/tairar/convis-legacy) リポジトリ参照

## 更新方法

このファイルはClaude Codeとの対話で作成・更新している。内容を更新したら、
このリポジトリのファイルを編集してコミットする。
